# Nightwatch

A minimal task manager, focus timer and notes pad for Chrome, set against a night skyline.

## Install
1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this folder.
3. Pin it, or open it with `Alt+Shift+B`.

## Use
- **Tasks**: add, check off, star (starred tasks stay on top), and double-click to edit. ▶ starts the timer on that task.
- **Timer**: 25/5/15 by default; change it with the sliders icon. It keeps running when the popup is closed, the icon badge shows the minutes left, and you get a notification at the end.
- **Notes**: saves automatically.
- **Stats**: focus time, sessions, tasks done, your day streak and the last 7 days.
- **⤢** opens everything in a full tab.

Keys: `1`–`4` switch views · `N` add a task · `Space` start or pause the timer

All data stays in `chrome.storage.local`, and the extension makes no network requests.
